Quiz 1 監督式學習・正面：公式與符號 MLP、LDA 不考｜橘字 = 必背數字或方向｜①模型②方法③解④評估／預測

① 線性迴歸 回歸｜參數模型

①ŷ = β0 + β1x；②調 β 使 SSE = Σ(y − ŷ)² 最小
③β1 = Σ(x−x̄)(y−ȳ) ÷ Σ(x−x̄)²；β0 = ȳ − β1x̄
④R² = 1 − SSE/SST，SST = Σ(y − ȳ)²
  • 直線必過 (x̄, ȳ)；殘差 e = y − ŷ
  • SST = SSR + SSE（總變異 = 已解釋 + 沒解釋），SSR = Σ(ŷ − ȳ)²；R² = SSR/SST；SSE 又稱 RSS
  • 假設 LINE：線性、獨立、常態、等變異
  • 弱點：離群值（平方放大）、曲線；R² 高 ≠ 模型對／準確率，看殘差規律
  • 多重共線性：係數不穩，預測影響小 → VIF、Ridge

② Ridge／Lasso 回歸｜正則化

①同線性　②Ridge（L2）：SSE + λΣβj²
Lasso（L1）：SSE + λΣ|βj|
③單特徵βR = Sxy ÷ (Sxx + λ)
βL = sign·max(|Sxy| − λ/2, 0) ÷ Sxx
  • Ridge 縮小但不會 = 0；Lasso 可 = 0 → 特徵選擇
  • λ 越大越強：偏差 ↑、變異 ↓，太大 → 欠擬合
  • 要先標準化（懲罰看係數大小）
  • Ridge 用「除」；Lasso 用「減」：|Sxy| 扣不過 λ/2 → 歸零；單特徵公式限特徵互不相關

③ 邏輯迴歸 分類｜輸出機率

①z = wx + b；p = σ(z) = 1 ÷ (1 + e−z)
ln(p ÷ (1 − p)) = z（log-odds）
②minL = −[y ln p + (1−y) ln(1−p)]
③梯度下降（無公式解）　④p ≥ 0.5 → 1
  • σ(0) = 0.5；z 大的正數 → 1，大的負數 → 0
  • 邊界 z = 0 → x = −b ÷ w，是直線（XOR 不行）
  • y = 1 只看 −ln p；越有把握地錯罰越重
  • 可分資料 w → ∞；C 越小正則化越強
  • 勝算比：x 增加 1，勝算 p/(1−p) 變 ew 倍

④ KNN 分類／回歸｜非參數

d = √[Σ(pj − qj)²]（歐氏）；曼哈頓 Σ|pj − qj|
分類：前 k 名多數決；回歸：前 k 名平均
Min-Max：x′ = (x − min) ÷ (max − min)
  • 不訓練（懶惰學習），預測慢
  • k 小 → 過擬合（雜訊）；k 大 → 欠擬合（多數類）
  • 必須標準化；兩類時 k 取奇數；高維度效果差
  • 距離加權：越近票越重

⑤ SVM 分類（SVR 回歸）

①f(x) = w·x + b；y ∈ {+1, −1}
②margin = 2 ÷ ‖w‖，‖w‖ = √(w1² + w2²)
min ½‖w‖² + C·Σ max(0, 1 − y·f)
③數值最佳化　④ŷ = sign(f)
  • y·f = 1：支援向量；< 1：在間隔內；< 0：判錯
  • C 大 → 間隔窄、過擬合；C 小 → 容許違規
  • 核函數（poly、rbf）處理非線性；rbf 的 γ 大 → 過擬合
  • 要標準化；大資料慢

⑥ 朴素貝氏 分類｜機率

P(C | x) = P(C)·P(x | C) ÷ P(x)
score(C) = P(C)·∏ P(xj | C)；後驗 = score ÷ Σscore
Laplace：(count + 1) ÷ (NC + 2)
  • 先驗 P(C)、似然 P(x|C)、後驗 P(C|x)
  • 假設：給定類別下特徵條件獨立
  • 零頻率 → 整個乘積 = 0 → Laplace 平滑（α = 1）
  • 相關特徵重複計算 → 機率過度自信；取 log 防下溢
  • Gaussian（連續）、Multinomial（次數）、Bernoulli（有無）

⑦ 決策樹 分類／回歸

Gini = 1 − Σpk²（兩類最大 0.5）
H = −Σpk log2 pk（兩類最大 1）
Gain = I父 − Σ(n子/n)·I子
  • 選增益最大的切法；純節點 = 0
  • 不需標準化；可解釋（if-else）
  • 易過擬合 → 最大深度、葉節點最少樣本數、剪枝 剪枝強度
  • 切線平行座標軸，斜線邊界要很多階

⑧ 隨機森林 Bagging

分類投票；回歸 ŷ = (1/B)Σŷb
Var = ρσ² + (1 − ρ)σ² ÷ B
  • bootstrap（有放回抽樣）＋每次切分隨機選特徵
  • 主要降變異；樹平行訓練
  • ρσ² 降不掉 → 每次切分的特徵數 小 → 樹更不像
  • 樹多（樹的棵數）不太會過擬合，只是變慢
  • 沒抽到的 OOB ≈ 36.8%（(1−1/n)n → e−1）可估誤差；單棵比亂猜差時越投越錯

⑨ 梯度提升 Boosting

F0 = ȳ；r = y − Fm−1
Fm = Fm−1 + η·hm（hm 擬合殘差）
  • 樹依序訓練，主要降偏差
  • 學習率 η 小＋輪數多較好；η 太大震盪
  • 輪數太多 → 背下雜訊 → early stopping
  • 最大深度 淺（3～8）、樣本抽樣比例；XGBoost／LightGBM

計算步驟速記

  • β1：求 x̄、ȳ → 離差相乘加總 ÷ x 離差平方加總；β0 = ȳ − β1x̄
  • R²：1 − SSE/SST（= SSR/SST）
  • Ridge／Lasso：算 Sxy、Sxx → Ridge ÷ (Sxx + λ)；Lasso |Sxy| − λ/2，負的 → 0，否則 ÷ Sxx、帶回正負號
  • 邏輯：z → p = 1/(1+e−z) → p ≥ 0.5 判 1 → L = −ln p（y=1）
  • KNN：算距離 → 排序 → 前 k 名投票
  • SVM：‖w‖ → 2/‖w‖；hinge 逐點 max(0, 1 − y·f) 加總 → ½‖w‖² + C·Σhinge
  • 貝氏：先驗 × 似然（各類）→ 除以總和
  • Gini 增益：父 − 加權子（權重 = 筆數比例）
  • RF：ρσ² + (1−ρ)σ²/B；多數決 = Σ C(B,m)pm(1−p)B−m
  • GB：r = y − F；F新 = F + η·h
  • F1：先 P、R，再 2PR/(P+R)
  • MAE／MSE／RMSE：列出 e → |e|、e² 加總 ÷ n → RMSE 開根號
  • Adj R²：代入 1 − (1 − R²)(n − 1)/(n − p − 1)

必背數字

  • σ(0) = 0.5；ln 1 = 0
  • Gini 兩類最大 0.5；熵兩類最大 1
  • margin = 2/‖w‖；支援向量 y·f = 1
  • Laplace：分子 +1、分母 +2（兩種情況）
  • R² ≤ 1；F1 ≤ (P+R)/2
  • e ≈ 2.718；e−1 ≈ 0.368（OOB 36.8%）

共通觀念與陷阱

  • 流程：資料 → 切訓練／測試 → 前處理（只用訓練資料 fit）→ 訓練 → 驗證調參 → 測試
  • 交叉驗證：K-fold 輪流當驗證集，取平均；用來選超參數
  • 資料洩漏：先在全部資料上標準化／補值再切分 ✗
  • 需標準化：KNN、SVM、Ridge/Lasso、邏輯迴歸（看距離或係數大小）
  • 不需要：樹、RF、GB（只比大小找切點）、朴素貝氏
  • 類別特徵：One-Hot（線性模型丟一欄當基準，避免共線）
  • 過擬合對策：更多資料、正則化、簡化模型、早停、集成
  • 欠擬合對策：更複雜模型、加特徵（多項式、交互項）、減正則化
  • 不平衡：加重少數類權重、重抽樣、調門檻、看 F1／AUC
