Quiz 1 監督式學習・正面：公式與符號 MLP、LDA 不考｜橘字 = 必背數字或方向｜①模型②方法③解④評估／預測

① 線性迴歸 回歸｜參數模型

①ŷ = β0 + β1x；②調 β 使 SSE = Σ(y − ŷ)² 最小
③β1 = Σ(x−x̄)(y−ȳ) ÷ Σ(x−x̄)²；β0 = ȳ − β1x̄
④R² = 1 − SSE/SST，SST = Σ(y − ȳ)²
  • 直線必過 (x̄, ȳ)；殘差 e = y − ŷ
  • 正規方程 β = (XᵀX)−1Xᵀy；特徵多 → 梯度下降／SGD
  • 梯度下降 w ← w − η∂L/∂w；η 太大發散
  • βj＝其他特徵固定時 xj +1 的變化；截距＝特徵全 0 的預測
  • AR(p)：過去 p 期的值當特徵，本質是線性迴歸
  • SST = SSR + SSE，SSR = Σ(ŷ − ȳ)²；R² = SSR/SST；SSE 又稱 RSS
  • 假設 LINE：線性、獨立、常態、等變異
  • 弱點：離群值、曲線；R² 高 ≠ 模型對／準確率；殘差漏斗＝異質變異
  • 共線性：係數不穩、預測影響小 → VIF、Ridge

② Ridge／Lasso 回歸｜正則化

①同線性　②Ridge（L2）：SSE + λΣβj²
Lasso（L1）：SSE + λΣ|βj|
③單特徵βR = Sxy ÷ (Sxx + λ)
βL = sign·max(|Sxy| − λ/2, 0) ÷ Sxx
  • Ridge 縮小但不會 = 0；Lasso 可 = 0 → 特徵選擇
  • λ↑ 越強：偏差↑ 變異↓，太大欠擬合
  • 要先標準化（懲罰看係數大小）
  • Ridge 用除、Lasso 用減（|Sxy| ≤ λ/2 → 0）；單特徵公式限特徵不相關
  • 矩陣閉式解 β = (XᵀX + λI)−1Xᵀy；Lasso 無閉式解
  • Elastic Net = L1 + L2；截距不罰；p > n 時 OLS 無唯一解，Ridge 可解

③ 邏輯迴歸 分類｜輸出機率

①z = wx + b；p = σ(z) = 1 ÷ (1 + e−z)
ln(p ÷ (1 − p)) = z（log-odds）
②minL = −[y ln p + (1−y) ln(1−p)]
③梯度下降，梯度 (p − y)x　④p ≥ 0.5 → 1
  • σ(0) = 0.5；z → +∞ 得 1、−∞ 得 0
  • 邊界 z = 0 → x = −b ÷ w，是直線（XOR 不行）
  • y = 1 用 −ln p、y = 0 用 −ln(1 − p)；越有把握地錯罰越重
  • 用 MLE 估參數（不用 MSE：非凸）；門檻↓ → Recall↑ Precision↓
  • 多類別：One-vs-Rest 或 Softmax
  • 可分資料 w → ∞；C 越小正則化越強
  • 勝算比：x 增加 1，勝算 p/(1−p) 變 ew 倍

④ KNN 分類／回歸｜非參數

Min-Max：x′ = (x − min) ÷ (max − min)
d = √[Σ(pj − qj)²]（歐氏）；曼哈頓 Σ|pj − qj|
分類：前 k 名多數決；回歸：前 k 名平均
  • 不訓練（懶惰學習），預測慢
  • k 小 → 過擬合（雜訊）；k 大 → 欠擬合（多數類）
  • 必須標準化；兩類時 k 取奇數；高維度效果差
  • 距離加權：越近票越重
  • 明氏 (Σ|pj − qj|r)1/r：r = 1 曼哈頓、r = 2 歐氏

⑤ SVM 分類（SVR 回歸）

①f(x) = w·x + b；y ∈ {+1, −1}
②margin = 2 ÷ ‖w‖，‖w‖ = √(w1² + w2²)
min ½‖w‖² + C·Σ max(0, 1 − y·f)
③數值最佳化　④ŷ = sign(f)
  • y·f = 1：支援向量；< 1：在間隔內；< 0：判錯
  • 只有支援向量決定邊界，遠處的點移動不影響
  • C 大 → 間隔窄、過擬合；C 小 → 容許違規
  • 核函數（poly、rbf）處理非線性；rbf 的 γ 大 → 過擬合
  • 要標準化；大資料慢

⑥ 朴素貝氏 分類｜機率

P(C | x) = P(C)·P(x | C) ÷ P(x)
score(C) = P(C)·∏ P(xj | C)；後驗 = score ÷ Σscore
Laplace：(count + 1) ÷ (NC + 2)
  • 先驗 P(C)、似然 P(x|C)、後驗 P(C|x)
  • 假設：給定類別下特徵條件獨立
  • 零頻率 → 乘積 = 0 → Laplace（α = 1）
  • 相關特徵重複計算 → 機率過度自信；取 log 防下溢
  • Gaussian（連續）、Multinomial（次數）、Bernoulli（有無）

⑦ 決策樹 分類／回歸

Gini = 1 − Σpk²（兩類最大 0.5）
H = −Σpk log2 pk（兩類最大 1）
Gain = I父 − Σ(n子/n)·I子
  • 選增益最大的切法；純節點 = 0
  • 不需標準化；可解釋（if-else）
  • 易過擬合 → 限深度、葉節點最少樣本數、剪枝
  • 回歸樹：MSE 最小切分、葉子取平均；CART 二元切分
  • 切線平行座標軸，斜線邊界要很多階
  • 貪婪：每步選當下最佳切法，不保證整棵最佳

⑧ 隨機森林 Bagging

分類投票；回歸 ŷ = (1/B)Σŷb
Var = ρσ² + (1 − ρ)σ² ÷ B
  • bootstrap（有放回抽樣）＋每次切分隨機選特徵
  • 每棵樹長深（低偏差高變異）；GB 才用淺樹
  • 每次切分常用 √p 個特徵；bootstrap 約 63.2% 不重複
  • 主要降變異；樹平行訓練
  • ρσ² 降不掉 → 每次切分的特徵數 小 → 樹更不像
  • 樹多不易過擬合，只變慢
  • 沒抽到的 OOB ≈ 36.8%（(1−1/n)n → e−1）可估誤差；單棵比亂猜差時越投越錯

⑨ 梯度提升 Boosting

F0 = ȳ；r = y − Fm−1
Fm = Fm−1 + η·hm（hm 擬合殘差）
  • 樹依序訓練，主要降偏差
  • 學習率 η 小＋輪數多較好；η 太大震盪
  • 輪數太多 → 背下雜訊 → early stopping
  • 最大深度 淺（3～8）、樣本抽樣比例；XGBoost／LightGBM
  • MSE 時殘差＝負梯度；XGBoost：加正則化、缺值自動分支；LightGBM：leaf-wise＋直方圖

計算步驟速記

  • β1：求 x̄、ȳ → 離差相乘加總 ÷ x 離差平方加總；β0 = ȳ − β1x̄
  • SST／SSR／SSE：算 ȳ、ŷ → SST = Σ(y − ȳ)²、SSE = Σ(y − ŷ)²、SSR = Σ(ŷ − ȳ)² → 驗算 SST = SSR + SSE → R² = SSR/SST = 1 − SSE/SST
  • 邏輯：z → p = 1/(1+e−z) → p ≥ 0.5 判 1 → L = −ln p（y=1）
  • KNN：算距離 → 排序 → 前 k 名投票
  • SVM：‖w‖ → 2/‖w‖；hinge 逐點 max(0, 1 − y·f) 加總 → ½‖w‖² + C·Σhinge
  • RF 多數決：Σ C(B,m)pm(1−p)B−m
  • MAE／MSE／RMSE：列出 e → |e|、e² 加總 ÷ n → RMSE 開根號

共通觀念與陷阱

  • 流程：資料 → 切訓練／測試 → 前處理（平均、標準差只用訓練資料算）→ 訓練 → 驗證調參 → 測試
  • 交叉驗證：K-fold 輪流當驗證集，取平均；用來選超參數
  • 網格搜尋：窮舉超參數組合＋交叉驗證；測試集只在最後用一次
  • 資料洩漏：測試（或未來）資料的資訊混進訓練 → 分數過度樂觀。例：先用全部資料算平均、補值再切分 ✗ → 應先切分，只用訓練資料算
  • 時間序列：依時間切分（過去訓練、未來驗證），不能打亂
  • 需標準化：KNN、SVM、Ridge/Lasso、邏輯迴歸（看距離或係數大小）
  • 不需要：樹、RF、GB（只比大小找切點）、朴素貝氏
  • 類別特徵：One-Hot（線性模型丟一欄當基準，避免共線）
  • 過擬合對策：更多資料、正則化、簡化模型、早停、集成
  • 欠擬合對策：更複雜模型、加特徵（多項式、交互項）、減正則化
  • 不平衡：加重少數類權重、重抽樣、調門檻、看 F1／AUC
