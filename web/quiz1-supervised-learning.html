01 · 共通觀念

每個演算法都會用到的觀念

學習流程

帶標籤資料 (X, y)→前處理→切 Train／Test→選演算法、設超參數→訓練 f(X; θ)→評估→預測 ŷ = f(Xnew)
  • 參數（parameter）是模型從資料學到的，例如迴歸係數 β。超參數（hyperparameter）是訓練前由人設定的，例如 KNN 的 k、樹的最大深度。
  • 測試集只能用來最後評估。調超參數要用驗證集或交叉驗證。

過擬合與欠擬合（Bias–Variance）

欠擬合 Underfitting過擬合 Overfitting
現象訓練、測試都差訓練很好、測試差
原因模型太簡單，偏差（Bias）高模型太複雜、記住雜訊，變異（Variance）高
對策加特徵、換更複雜的模型、減弱正則化加資料、正則化、剪枝、減少特徵、交叉驗證、集成

交叉驗證（Cross-Validation）

k-fold：把訓練資料切成 k 份，輪流拿 1 份當驗證、其餘 k−1 份訓練，做 k 次後取平均分數。結果比只切一次更穩定。分類問題常用 Stratified k-fold，讓每份的類別比例一致。

超參數搜尋：Grid Search（窮舉所有組合）、Random Search（隨機抽組合，參數多時較快）、Bayesian Optimization（依先前結果挑下一組）。

資料前處理

問題做法
缺值刪除，或用平均數／中位數／眾數補值
類別特徵One-Hot Encoding。線性迴歸要丟掉一欄，避免虛擬變數陷阱（Dummy Variable Trap，欄位完全共線）

哪些演算法需要特徵縮放？

  • 需要：KNN、SVM（距離或內積）、Ridge／Lasso、邏輯迴歸（正則化會受尺度影響），以及用梯度下降訓練的模型。
  • 不需要：決策樹、隨機森林、梯度提升樹，因為樹只比較大小、找切點。
  • 朴素貝氏也不需要，它是對每個特徵各自估計機率分布。
  • 資料洩漏（Data Leakage）：標準化的平均、標準差要只用訓練集算出，再套用到測試集。用全部資料算會讓測試分數偏高。

算一次看看

TP = 40、FP = 10、FN = 20、TN = 30（共 100 筆）：

  • 先算三個分母：預測為正 TP + FP = 40 + 10 = 50；實際為正 TP + FN = 40 + 20 = 60；實際為負 TN + FP = 30 + 10 = 40
  • Accuracy = (TP + TN) / 全部 = (40 + 30) / 100 = 0.70
  • Precision = TP / (TP + FP) = 40 / 50 = 0.80
  • Recall = TP / (TP + FN) = 40 / 60 ≈ 0.667
  • Specificity = TN / (TN + FP) = 30 / 40 = 0.75，所以 FPR = 1 − 0.75 = 0.25
  • F1 = 2PR / (P + R)：分子 2 × 0.8 × 0.667 ≈ 1.067，分母 0.8 + 0.667 = 1.467，F1 = 1.067 / 1.467 ≈ 0.727（也可以用 2TP / (2TP + FP + FN) = 80 / 110 ≈ 0.727 驗算）
  • 95% 是負例的資料，模型全部猜負就有 95% Accuracy，但 Recall = 0。不平衡資料不要只看 Accuracy。
  • Precision 和 Recall 通常此消彼長：調高分類門檻 → Precision 上升、Recall 下降。

正式說明：給定 n 筆資料 (xi, yi)，找一條直線 ŷ = β0 + β1x，讓所有點的殘差平方和 SSE = Σ(yi − ŷi)² 最小（最小平方法）。把 SSE 分別對 β0、β1 微分、令它等於 0，就能解出 ③ 的公式，不用一條一條線去試。這是在「預測連續數值」的問題裡，最簡單、可以直接解出答案的模型。

白話說明

假設你蒐集了幾間房子的坪數和房價，畫在圖上是一堆散開的點。你想要一個「看坪數就能估房價」的規則。最簡單的規則就是一條直線：房價 = 起始價 + 每坪單價 × 坪數。起始價就是截距 β0，每坪單價就是斜率 β1。

麻煩的是，點不會剛好排成一直線，你可以畫出無數條線，到底哪一條「最好」？線性迴歸的回答是：任何一條線都會和每個點有落差（叫做殘差，實際值減預測值）。把每個落差平方、全部加起來，總和最小的那條線就是最好的線，這就是「最小平方法」名字的由來。

為什麼要平方，不直接相加？① 落差有正有負，直接相加會互相抵銷，看起來總誤差很小其實很差；平方後全部變成正數。② 平方會讓大錯被罰得特別重（差 2 罰 4、差 10 罰 100），所以直線會盡量不離任何一個點太遠。這也正是它的弱點：一個離得很遠的點，平方後的罰分會大到把整條線拉過去（見下面「解決不了 2」）。

好消息是，這個「最小」不用一條一條線去試，可以直接算出來：斜率 = x 和 y「一起變動」的程度 ÷ x「自己變動」的程度。截距則保證這條線一定會通過所有資料的平均點 (x̄, ȳ)。

常考陷阱

  • 多重共線性不太影響預測能力，但會讓係數忽大忽小、正負號亂跳，難以解釋。用 VIF 檢查，或改用 Ridge。
  • 非線性關係可以先做多項式特徵（Polynomial Features），模型對係數仍然是線性的，所以還是線性迴歸。
  • One-Hot 後要丟掉一欄當基準，否則虛擬變數加總恆為 1，和截距完全共線。
  • 特徵選擇常用逐步法：Backward Elimination（從全部開始，逐一刪掉 p-value 最大的）。
考前重點
  • 用途：預測連續數值；係數可以直接解讀成「x 增加 1，y 平均變化多少」，常拿來當基線模型。
  • 和邏輯迴歸的差別：線性迴歸輸出任意實數、最小化 SSE；邏輯迴歸多一個 sigmoid，輸出 0～1 的機率、最小化 log-loss，用來分類。
  • 最常考：R² 的意義、R² 高不代表模型對（要看殘差）、對離群值敏感、多重共線性讓係數不穩但不太影響預測。

正式說明：在線性迴歸的誤差後面加一個「係數大小的懲罰項」。Ridge 用係數平方（L2），會把所有係數往 0 縮但不會等於 0；Lasso 用係數絕對值（L1），會把影響小的係數直接壓成 0，等於自動做特徵選擇。λ 控制懲罰多強。上面 ③ 的「單一特徵」解適用於特徵彼此不相關（正交）的情況，每個係數可以分開算。一般情況下，Ridge 仍有公式解；Lasso 因為絕對值在 0 的地方不能微分，沒有公式解，要用數值方法反覆逼近。

白話說明

普通的線性迴歸只在乎「誤差最小」，為了把訓練資料的每一點都擬合好，它可能給某些特徵很誇張的係數，例如 +500、−480 互相抵銷。在訓練資料上看起來很準，換一批新資料就失準，這就是過擬合。特徵很多、或特徵彼此高度相關時特別容易發生。

Ridge／Lasso 的想法是：誤差要小，但係數也不能太誇張。所以在誤差後面加一個「係數越大罰越多」的項，讓模型在兩者之間取捨。λ 就是你有多在意「係數不要太大」：λ = 0 時完全不在意，就是普通線性迴歸；λ 很大時非常在意，係數會被壓得很小。

兩者的差別在罰法：Ridge 罰「係數的平方」，係數越接近 0，平方越小，罰分幾乎消失，所以它會把係數縮小，但不會縮到剛好 0。Lasso 罰「係數的絕對值」，係數從 0.1 降到 0 一樣可以少罰 0.1 × λ，所以對影響不大的特徵，它乾脆把係數設成 0，等於把那個特徵刪掉。

用一句話記：Ridge 是「大家都瘦一點」，Lasso 是「不重要的直接淘汰」。

補充：公式怎麼來、為什麼是 λ/2

白話說明

假設你想用「讀書時數」預測「考試會不會及格」。答案只有兩種：及格（1）或不及格（0）。如果直接用線性迴歸畫一條線，讀很少的人會被預測成 −0.3、讀很多的人變成 1.4，這些數字既不是 0／1，也不是機率，很難解釋。

邏輯迴歸分兩步：第一步和線性迴歸一樣，算一個「分數」z = w × 讀書時數 + b，分數可以是任何數。第二步把分數丟進 sigmoid 函數，它像一個「壓縮器」：分數是很大的正數（例如 z = 10）會被壓到接近 1（0.99995）；分數是很大的負數（例如 z = −10）會被壓到接近 0（0.00005）；分數剛好是 0 時，e0 = 1，所以 p = 1 ÷ (1 + 1) = 0.5，表示「一半一半、沒有把握」。分數離 0 越遠，模型越有把握。這樣輸出就變成「及格的機率」。機率 ≥ 0.5 就判及格。

那 w、b 怎麼決定？用 log-loss 打分數：真的及格的人，模型給的及格機率越高，罰得越少；模型很有把握說「會及格（p = 0.99）」結果不及格，罰得非常重。訓練就是調 w、b，讓所有人的平均罰分最小。

因為「機率 = 0.5」剛好等於「分數 z = 0」，而 z = wx + b = 0 是一條直線，所以邏輯迴歸切開兩類的邊界一定是直線（多個特徵時是平面）。這是它的優點（簡單、可解釋），也是它的限制（見下面「解決不了 1」）。

計算範例

06 · 距離

K 近鄰 K-Nearest Neighbors（KNN）

分類／回歸懶惰學習無參數需要標準化

正式說明：KNN 不學參數。預測時計算新資料點到每一筆訓練資料的距離，取距離最小的 k 筆，分類用多數決、回歸取平均。它假設「特徵相近的資料，答案也相近」。

白話說明

想像你搬到新社區，想知道某家餐廳好不好吃，最直覺的做法是問住最近的幾個鄰居：3 個人裡 2 個說好吃，你就猜好吃。KNN 就是這樣：新資料進來，找訓練資料裡最像它的 k 筆，看它們的答案。

「最像」用距離衡量。每筆資料是一串數字（特徵），可以想成空間中的一個點，兩點的直線距離越短就越像。距離公式就是國中學過的畢氏定理：每個特徵相減、平方、加總、開根號。

KNN 沒有「訓練」這一步，只是把資料存起來（所以又叫懶惰學習），所有計算都在預測時才做。代價是預測很慢：每來一筆新資料，都要和所有訓練資料算一次距離。

它有兩個關鍵要調：k 要多大（太小會被單一個怪點誤導，太大會被數量多的類別淹沒），以及特徵要先標準化（否則數字大的特徵會獨占距離）。下面兩個「解決不了」就是這兩件事。

正式說明：在能把兩類分開的所有直線（超平面）中，SVM 選間隔最大的一條。把 f(x) 縮放成「最近的點剛好 y · f(x) = 1」之後，間隔等於 2 ÷ ‖w‖，所以「間隔最大」等於「‖w‖ 最小」。資料分不乾淨時，加上 hinge loss 容許少數點違規（軟間隔），由 C 控制取捨。這個最佳化問題沒有像線性迴歸那樣的公式解，要用數值方法求解；解出來的分隔線只由支援向量決定，其他點移動（只要不跨進間隔）都不影響結果。

白話說明

想像桌上有紅豆和綠豆兩堆，你要放一根筷子把它們分開。能分開的擺法通常有很多種，有的筷子緊貼著紅豆、有的緊貼著綠豆。哪一種最好？SVM 的答案是：放在正中間、離兩堆最近的豆子都最遠的那一種。這樣新的豆子即使位置稍微偏一點，也比較不會被分錯。

想像那根筷子變成一條「馬路」：中線是分隔線，兩邊路緣碰到最近的豆子。SVM 要找「最寬的馬路」。剛好碰到路緣的那幾顆豆子叫支援向量，馬路的位置完全由它們決定，其他離得遠的豆子移動一點也不會改變答案。

數學上，馬路寬度 = 2 ÷ ‖w‖，所以要馬路最寬，就是要 w 最短。真實資料常常有幾顆豆子混到對方那堆，不可能完全分開，這時允許少數豆子「踩進馬路或越線」，但每違規一顆就罰分（hinge loss），C 決定罰多重。

如果兩堆豆子交錯得根本無法用直線分開，SVM 還有一招：核函數。把資料「抬」到更高維度，例如多加一個特徵 x1 × x2，原本交錯的資料就可能變得用一個平面就分得開（見「解決不了 1」）。

08 · 機率

朴素貝氏 Naive Bayes

分類生成式模型訓練極快

用貝氏定理算「看到這些特徵時，屬於每一類的機率」，取最大的。「朴素」是指假設特徵之間在給定類別下互相獨立。

白話說明

你收到一封信，裡面有「免費」兩個字，它是垃圾信嗎？直接回答很難，但反過來的問題很好查：翻翻以前的信，垃圾信裡有幾成出現「免費」？正常信裡又有幾成？貝氏定理就是把這個「反方向」的資訊轉回你要的答案。

計算分兩部分相乘：這一類本來就有多常見（先驗，例如 10 封信裡 4 封是垃圾信），乘上這一類的信出現這個字的比例（似然）。哪一類乘出來比較大，就猜哪一類。把各類的乘積加總、再各自除以總和，就換算成機率。

信裡通常不只一個字。嚴格來說要知道「同時出現這些字」的機率，但字的組合太多，資料根本不夠估。朴素貝氏「天真地」假設每個字出不出現互不影響，於是只要把每個字的比例分別乘起來。這個假設通常不完全對，但算得快、需要的資料少，在文字分類上效果意外地好。

要小心兩件事：某個字在某一類從沒出現過，乘上 0 就讓整個分數歸零（用 Laplace 平滑解決）；以及特徵其實高度相關時，同一個證據會被重複計算（見下面兩個「解決不了」）。

計算範例

✅ 解決得了：信裡有「免費」，是垃圾信的機率多少？

訓練資料 10 封：垃圾信 4 封，其中 3 封有「免費」；正常信 6 封，其中 1 封有「免費」。

STEP 1先驗：P(垃圾) = 4/10 = 0.4，P(正常) = 6/10 = 0.6

STEP 2似然：P(免費 | 垃圾) = 3/4 = 0.75，P(免費 | 正常) = 1/6 ≈ 0.167

STEP 3分數：垃圾 0.4 × 0.75 = 0.3；正常 0.6 × 1/6 = 0.1

STEP 4換算成機率：P(垃圾 | 免費) = 0.3 ÷ (0.3 + 0.1) = 0.75

分母 0.3 + 0.1 = 0.4 其實就是 P(免費)：10 封裡有 3 + 1 = 4 封含「免費」，4/10 = 0.4。同理 P(正常 | 免費) = 0.1 ÷ 0.4 = 0.25，兩者加起來剛好是 1。

解讀：雖然垃圾信只佔 4 成，但「免費」在垃圾信裡太常見（75% vs 17%），看到它之後，垃圾信的機率從 40% 升到 75%。這就是「用證據更新判斷」。

❌ 解決不了 1：沒見過的組合讓機率變成 0（零頻率問題）

另一個字「會議」：垃圾信 0 封有、正常信 3 封有。新信同時有「免費」和「會議」：

為什麼解決不了：連乘中只要有一項是 0，其他證據再強也沒用，結果永遠是 0。只因為訓練資料裡剛好沒有「含『會議』的垃圾信」，模型就斷定這種信絕不可能是垃圾信。對策：Laplace 平滑，每個計數都先加 α（通常 1），沒見過的情況也保留一點小機率。平滑後結論變成「37% 是垃圾信」，比較合理。平滑參數 α 通常預設就是 1。

❌ 解決不了 2：特徵其實相關，同一個證據被算兩次

假設還有一個字「限時免費」，它出現的信剛好就是有「免費」的那些（兩個字總是一起出現），比例完全相同：垃圾 3/4、正常 1/6。新信兩個字都有：

垃圾分數 0.4 × 0.75 × 0.75 = 0.225；正常分數 0.6 × 1/6 × 1/6 = 0.0167；P(垃圾) = 0.225 ÷ (0.225 + 0.0167) = 0.931

為什麼解決不了：「限時免費」沒有提供任何新資訊（只要有它就一定有「免費」），正確答案仍應是 0.75。但朴素假設把兩個字當成獨立的兩個證據，相同的訊息乘了兩次，機率被誇大到 0.93，模型變得過度自信。對策：先移除高度相關的重複特徵；朴素貝氏的「分類結果」常常仍然正確，但它給的「機率數值」不要太相信。

拉普拉斯平滑（Laplace Smoothing）

如果某個字在訓練資料的某類別裡從沒出現，P(xj|y) = 0，整串連乘就變 0。解法是每個計數都加 α（通常 α = 1）。

優點
  • 訓練和預測都極快
  • 小資料、高維資料（文字）表現好
  • 新資料進來只要更新計數，可以逐批更新
缺點
  • 獨立假設通常不成立
  • 輸出的機率值不準（太接近 0 或 1）
  • 特徵相關性強時效果下降

常考陷阱

  • 獨立假設雖然常不成立，但只要機率的大小順序對，分類結果還是準。
  • 零機率問題 → 拉普拉斯平滑。
  • 它是生成式模型：先學每一類「長什麼樣」P(x|y)，再反推 P(y|x)。
考前重點
  • 用途：文字分類（垃圾信、情緒分析）的快速基線，資料少也能用，訓練與預測都極快。
  • 和邏輯迴歸的差別：朴素貝氏是生成模型（學每一類怎麼產生特徵，P(x | C)），邏輯迴歸是判別模型（直接學分界）。
  • 最常考：條件獨立假設；零頻率問題用 Laplace 平滑；分類結果常常對，但給的機率偏極端、不可盡信。

白話說明

決策樹就像玩「猜猜我是誰」：每次問一個是非題，把可能的答案切成兩群，越問越接近答案。例如判斷會不會去打球：先問「天氣晴嗎？」再問「濕度高嗎？」……最後得到一串 if-else 規則。

關鍵是每一步要問哪一題。好問題能把資料分得很「乾淨」：問完之後，左邊幾乎全是「去」、右邊幾乎全是「不去」。爛問題問完兩邊還是一半一半，等於沒問。

「乾淨」要用數字衡量，這就是 Gini 和熵。Gini 可以想成：從這群資料隨便抽兩筆，類別不一樣的機率。全部同一類 → 不可能抽到不一樣 → 0；一半一半 → 最容易抽到不一樣 → 最大。熵是同一個概念的另一種算法。

樹會把每個候選問題都試一次，算「問之前的不純度 − 問之後兩邊的加權不純度」，也就是這題讓資料變乾淨多少，然後選變乾淨最多的那一題。重複這個過程，樹就長出來了。

白話說明

一棵長到很深的決策樹很聰明，但很神經質：訓練資料稍微換一點，它長出來的樣子就差很多，預測也跟著大幅晃動（變異大、容易過擬合）。

隨機森林的想法是「三個臭皮匠，勝過一個諸葛亮」：訓練很多棵樹，讓它們投票。每棵樹各自會犯錯，但如果它們犯的錯不一樣，投票時錯誤會互相抵消，多數意見通常是對的。

重點在「犯的錯不一樣」。如果 100 棵樹都用一模一樣的資料、一模一樣的方法訓練，它們會長得一模一樣、犯一樣的錯，投票就沒有意義。所以隨機森林刻意加入兩種隨機：每棵樹抽不同的資料（bootstrap），每次切分只看部分特徵，讓每棵樹「各有各的觀點」。

變異數公式把這件事說得很清楚：Var = ρσ² + (1 − ρ)σ²/B。第二項會隨樹變多而縮小，但第一項 ρσ² 跟樹的數量無關。樹之間越不像（ρ 越小），加樹越有用；樹之間很像，加再多也沒用。

兩種隨機

  1. 資料隨機（Bootstrap）：每棵樹從訓練集有放回地抽 n 筆。每次約有 63.2% 的不同樣本被抽到，剩下約 36.8% 沒被抽到，稱為 OOB（Out-of-Bag）樣本。

  • Bootstrap 是有放回抽樣，同一筆資料可能被抽到好幾次。
考前重點
  • 用途：表格資料的穩健預設選擇，不太需要調參就有不錯表現，還能看特徵重要度。
  • 和決策樹、梯度提升的差別：比單棵樹穩定（降變異）；和梯度提升相比，各棵樹是平行、獨立訓練，不是一棵接一棵修正。
  • 最常考：bootstrap 加隨機選特徵；每棵樹約有 36.8% 資料沒抽到（OOB）；樹多不太會過擬合；樹之間太像（ρ 大）時加樹沒用。

梯度提升 Gradient Boosting（XGBoost／LightGBM）

分類／回歸Boosting循序訓練

一棵接一棵訓練淺樹，每棵新樹專門學「前面所有樹加起來還錯多少」（殘差），再用小步伐加進模型。

正式說明：梯度提升從一個簡單的預測（平均值）開始，每一輪訓練一棵淺樹去擬合目前的殘差（平方誤差的負梯度），再把這棵樹的輸出乘上學習率 η 加進模型。重複 M 輪，模型是所有樹的加總。和隨機森林「平行訓練、平均」不同，梯度提升是「依序訓練、逐步修正」。

白話說明

想像你在打高爾夫球。第一桿先往洞的大方向打（預測平均值）。球停下來後，看還差多少、往哪個方向差，第二桿只負責修正這段差距。再看還差多少，第三桿再修……每一桿都比上一桿更接近洞口。

梯度提升就是這樣：第一棵「樹」其實只是平均值，誤差很大。第二棵樹不重新學 y，而是學「上一輪還錯多少」（殘差），把這個修正加上去，誤差就變小。第三棵再學新的殘差……每棵新樹都在補前面的不足。

每一桿不要用全力打，這就是學習率 η：每棵樹算出的修正只加上 η 倍（例如一半）。看起來比較慢，但不容易「打過頭」，也比較不會把雜訊學進去，最後通常更準。

和隨機森林比較：隨機森林是很多人同時各自猜、再平均，主要降低「晃動」（變異）；梯度提升是一個接一個接力修正，主要降低「系統性的偏差」。所以梯度提升通常更準，但也更容易過擬合，需要小心調 η 和輪數。

逐步相加Fm(x) = Fm−1(x) + η · hm(x)
  • hm 是第 m 棵樹，擬合損失函數的負梯度；用 MSE 時，負梯度剛好就是殘差 y − Fm−1(x)。
  • η 是學習率（learning rate），讓每棵樹只修正一點，避免一次修過頭。

XGBoost／LightGBM 改進了什麼

重點
XGBoost損失函數加入正則化項；用二階導數（梯度和 Hessian）找切點；內建處理缺值（學每個切點缺值該往哪邊走）；切點搜尋可平行化
LightGBM直方圖分箱加速；樹按葉生長（leaf-wise），每次挑誤差下降最多的葉子長，資料大時更快
優點
  • 結構化（表格）資料上常是準確度最高的
  • 支援正則化、缺值、自訂損失
  • 提供特徵重要性；不需要標準化
缺點
  • 超參數多、要仔細調
  • 樹要依序訓練，無法跨樹平行
  • 對雜訊和離群值較敏感，容易過擬合

常考陷阱

  • Boosting 是循序的，每棵樹依賴前一棵；Bagging 是平行的。
  • XGBoost、LightGBM 都是梯度提升的實作：加入正則化、抽樣、更快的切點搜尋，是表格資料常用的高分方法。
  • AdaBoost 也是 Boosting，但它是調整樣本權重（加重錯分的點）；梯度提升是擬合殘差／負梯度。
考前重點
  • 用途：表格資料最常拿到最好成績的方法之一；XGBoost、LightGBM 都是它的高效實作。
  • 和隨機森林的差別：樹一棵接一棵訓練、每棵擬合前面的殘差，主要降低偏差；所以樹要淺、學習率要小。
  • 最常考：Fm = Fm−1 + η · hm；η 太大會震盪、輪數太多會過擬合，用早停決定輪數；η 調小要配更多棵樹。
