01 · 共通觀念

每個演算法都會用到的觀念

學習流程

帶標籤資料 (X, y)→前處理→切 Train／Test→選演算法、設超參數→訓練 f(X; θ)→評估→預測 ŷ = f(Xnew)
  • 參數（parameter）是模型從資料學到的，例如迴歸係數 β。超參數（hyperparameter）是訓練前由人設定的，例如 KNN 的 k、樹的最大深度。
  • 測試集只能用來最後評估。調超參數要用驗證集或交叉驗證。

過擬合與欠擬合（Bias–Variance）

欠擬合 Underfitting過擬合 Overfitting
現象訓練、測試都差訓練很好、測試差
原因模型太簡單，偏差（Bias）高模型太複雜、記住雜訊，變異（Variance）高
對策加特徵、換更複雜的模型、減弱正則化加資料、正則化、剪枝、減少特徵、交叉驗證、集成

交叉驗證（Cross-Validation）

k-fold：把訓練資料切成 k 份，輪流拿 1 份當驗證、其餘 k−1 份訓練，做 k 次後取平均分數。結果比只切一次更穩定。分類問題常用 Stratified k-fold，讓每份的類別比例一致。

超參數搜尋：Grid Search（窮舉所有組合）、Random Search（隨機抽組合，參數多時較快）、Bayesian Optimization（依先前結果挑下一組）。

資料前處理

問題做法
缺值刪除，或用平均數／中位數／眾數補值
類別特徵One-Hot Encoding。線性迴歸要丟掉一欄，避免虛擬變數陷阱（Dummy Variable Trap，欄位完全共線）
特徵尺度不同標準化 StandardScaler（平均 0、標準差 1），或正規化 MinMaxScaler（縮到 0～1）
類別不平衡過採樣（SMOTE）、欠採樣、class_weight='balanced'，改看 Recall／F1／AUC

哪些演算法需要特徵縮放？

  • 需要：KNN、SVM（距離或內積）、Ridge／Lasso、邏輯迴歸（正則化會受尺度影響），以及用梯度下降訓練的模型。
  • 不需要：決策樹、隨機森林、梯度提升樹，因為樹只比較大小、找切點。
  • 朴素貝氏也不需要，它是對每個特徵各自估計機率分布。
  • 資料洩漏（Data Leakage）：Scaler 要只用訓練集 fit，再對測試集 transform。用全部資料 fit 會讓測試分數偏高。

算一次看看

TP = 40、FP = 10、FN = 20、TN = 30（共 100 筆）：

  • Accuracy = 70 / 100 = 0.70
  • Precision = 40 / 50 = 0.80
  • Recall = 40 / 60 ≈ 0.667
  • F1 = 2 × 0.8 × 0.667 / (0.8 + 0.667) ≈ 0.727
  • 95% 是負例的資料，模型全部猜負就有 95% Accuracy，但 Recall = 0。不平衡資料不要只看 Accuracy。
  • Precision 和 Recall 通常此消彼長：調高分類門檻 → Precision 上升、Recall 下降。

03 · 線性模型

線性迴歸 Linear Regression

回歸參數模型可解釋

假設 y 和特徵呈線性關係，找出讓「實際值與預測值差的平方和」最小的係數。

模型與目標

模型ŷ = β0 + β1x1 + β2x2 + ⋯ + βpxp
OLS 目標β* = arg minβ Σi (yi − ŷi)²解析解β = (XᵀX)−1Xᵀy
  • 普通最小平方法（OLS）：最小化殘差平方和（SSE）。可以直接用解析解，也可以用梯度下降。
  • 係數解讀：其他特徵固定時，xj 增加 1，y 平均變化 βj。
  • 只有一個特徵叫簡單線性迴歸，多個特徵叫多元線性迴歸。

基本假設（LINE）

Linearity特徵與 y 呈線性關係
Independence誤差彼此獨立
Normality誤差呈常態分布
Equal variance誤差變異數固定（同質變異，Homoscedasticity）
另外特徵之間沒有嚴重的多重共線性（Multicollinearity）
優點
  • 簡單、訓練快
  • 係數可以直接解釋
  • 常拿來當基線模型
缺點
  • 只能表達線性關係
  • 平方誤差讓它對離群值敏感
  • 多重共線性讓係數不穩定

常考陷阱

  • 多重共線性不太影響預測能力，但會讓係數忽大忽小、正負號亂跳，難以解釋。用 VIF 檢查，或改用 Ridge。
  • 非線性關係可以先做多項式特徵（Polynomial Features），模型對係數仍然是線性的，所以還是線性迴歸。
  • One-Hot 後要丟一欄（drop_first=True），否則虛擬變數完全共線。
  • 特徵選擇常用逐步法：Backward Elimination（從全部開始，逐一刪掉 p-value 最大的）。
from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X_train, y_train)
model.coef_, model.intercept_      # β1..βp、β0
model.score(X_test, y_test)        # R²
04 · 線性模型

Ridge／Lasso 迴歸

回歸正則化需要標準化

在線性迴歸的損失函數加上「係數太大的懲罰」，用一點偏差換更低的變異，減少過擬合。

Ridge（L2）Loss = Σ (yi − ŷi)² + α Σ βj²
Lasso（L1）Loss = Σ (yi − ŷi)² + α Σ |βj|
Ridge（L2）Lasso（L1）
懲罰項係數平方和係數絕對值和
對係數的效果全部縮小，但不會變成 0可以把係數壓到剛好 0 → 稀疏
特徵選擇不會會（係數為 0 的特徵等於被刪掉）
多重共線性處理得好，相關特徵會平分權重相關特徵中常只留一個，選哪個不穩定
適合很多特徵都有點用只有少數特徵真的有用
  • α（alpha）：懲罰強度。α = 0 就是普通線性迴歸；α 越大 → 係數越小 → 偏差升高、變異降低，太大會欠擬合。用交叉驗證挑（RidgeCV、LassoCV）。
  • Elastic Net 同時加 L1 和 L2，用 l1_ratio 調比例。
  • 截距 β0 不加懲罰。
優點
  • 降低過擬合
  • Ridge 穩定共線性係數
  • Lasso 自動做特徵選擇
缺點
  • 仍然只有線性關係
  • 要調 α
  • 一定要先標準化特徵

常考陷阱

  • 懲罰的是係數大小，特徵尺度不同時懲罰不公平，所以必須先標準化。
  • 記法：L1 → 一刀砍到 0（稀疏）；L2 → 平方，大的係數罰更多，但只縮不砍。
  • sklearn 的 Ridge／Lasso 用 alpha，越大越強；邏輯迴歸用 C，是倒數，越小越強。
from sklearn.linear_model import Ridge, Lasso
Ridge(alpha=1.0).fit(X_train_scaled, y_train)
Lasso(alpha=0.1).fit(X_train_scaled, y_train)   # coef_ 會有 0
05 · 線性模型

邏輯迴歸 Logistic Regression

分類輸出機率線性決策邊界

名字有「迴歸」但做的是分類：把線性組合丟進 Sigmoid，得到屬於正類的機率，再用門檻（通常 0.5）決定類別。

線性部分z = wᵀx + bSigmoidp = σ(z) = 11 + e−z
Log-oddsln p1 − p = wᵀx + b
損失（Log Loss／Cross-Entropy）L = −[ y ln p + (1 − y) ln(1 − p) ]
  • Sigmoid 把任意實數壓到 (0, 1)。z = 0 時 p = 0.5，那就是決策邊界 wᵀx + b = 0，所以邊界是線性的。
  • 用最大概似估計（MLE）求參數，等同最小化 Log Loss。沒有解析解，用梯度下降等迭代法。
  • 係數解讀：xj 增加 1，log-odds 增加 wj，勝算（odds）變成 ewj 倍。
  • 多類別：One-vs-Rest（每類各訓練一個二元分類器）或 Softmax（Multinomial）。

重要超參數

C正則化強度的倒數（C = 1/λ）。C 小 → 正則化強 → 模型簡單；C 大 → 容易過擬合
penalty預設 L2；也可用 L1（要搭配支援的 solver，如 liblinear、saga）
class_weight不平衡資料可設 'balanced'
優點
  • 簡單、快、可解釋
  • 輸出機率，可以自己調門檻
  • 分類的基線模型
缺點
  • 只能畫線性邊界（非線性要自己做特徵）
  • 對特徵尺度敏感
  • 特徵高度相關時係數不穩

常考陷阱

  • 它是分類演算法，不是回歸。
  • 為什麼不用 MSE 當損失？套上 Sigmoid 後 MSE 不是凸函數，有很多局部最小值；Log Loss 是凸的。
  • 邏輯迴歸是判別式模型（直接學 P(y|x)），朴素貝氏是生成式模型（學 P(x|y) 和 P(y)）。
  • 門檻不一定要 0.5：要提高 Recall 就調低門檻。
from sklearn.linear_model import LogisticRegression
clf = LogisticRegression(C=1.0).fit(X_train_scaled, y_train)
clf.predict_proba(X_test_scaled)[:, 1]   # 屬於正類的機率
06 · 距離

K 近鄰 K-Nearest Neighbors（KNN）

分類／回歸懶惰學習無參數需要標準化

新資料進來時，找訓練集中距離最近的 k 筆。分類用多數決，回歸取平均。

歐氏距離d(x, x′) = √Σ (xj − x′j)²曼哈頓距離d = Σ |xj − x′j|
  • 懶惰學習（Lazy Learning）：訓練階段只是把資料存起來，沒有學參數；計算都在預測時做，所以訓練快、預測慢。
  • 無母數（Non-parametric）：不假設資料分布的形式。

重要超參數

超參數效果
n_neighbors（k）k 小 → 邊界彎曲、受雜訊影響 → 過擬合（k = 1 時訓練準確率 100%）。k 大 → 邊界平滑 → 欠擬合。用交叉驗證挑；二元分類常取奇數避免平手
weights'uniform' 每個鄰居一票；'distance' 越近的權重越大
metric距離定義：歐氏、曼哈頓、Minkowski（p=1 曼哈頓、p=2 歐氏）
優點
  • 直觀，沒有訓練過程
  • 能處理非線性邊界
  • 新增資料不用重新訓練
缺點
  • 預測時要跟每一筆算距離，資料多就慢、吃記憶體
  • 對特徵尺度、不相關特徵敏感
  • 維度高時效果差（維度詛咒）

常考陷阱

  • 一定要標準化：例如「年收入（萬）」和「年齡」放一起，距離幾乎只看收入。
  • 維度詛咒（Curse of Dimensionality）：維度高時所有點之間的距離都差不多，「最近」就失去意義。
  • KNN 的 k 是鄰居數；K-Means 的 k 是群數，而且 K-Means 是非監督式。不要搞混。
from sklearn.neighbors import KNeighborsClassifier
KNeighborsClassifier(n_neighbors=5).fit(X_train_scaled, y_train)
07 · 間隔最大化

支援向量機 Support Vector Machine（SVM）

分類（SVC）／回歸（SVR）核技巧需要標準化

在兩類之間找一條「離兩邊最近的點都最遠」的分隔超平面，也就是間隔（margin）最大的那條。

超平面wᵀx + b = 0間隔寬度2‖w‖Hinge Lossmax(0, 1 − y·f(x))
  • 支援向量（Support Vectors）：落在間隔邊界上或間隔內的點。只有它們決定超平面，其他點拿掉不影響結果。
  • Hard margin 要求完全分開；Soft margin 允許部分點越界，用 C 控制容忍度。
  • 核技巧（Kernel Trick）：不實際把資料映射到高維，只用核函數算高維空間的內積，就能在原空間畫出非線性邊界。
  • SVR：在預測線周圍畫一條寬 ε 的管子，管內誤差不計（ε-insensitive loss），只懲罰管外的點。

核函數

kernel形式用途
linearxᵀx′線性可分、特徵很多（如文字）
poly(γ xᵀx′ + r)d多項式邊界
rbf（預設）exp(−γ ‖x − x′‖²)最常用的非線性核

重要超參數

超參數變大會怎樣
C越不容忍錯誤 → 間隔變窄、邊界貼著訓練資料 → 容易過擬合。C 小 → 間隔寬、容許錯分 → 較平滑
gamma（γ，RBF）每個點的影響範圍變小 → 邊界彎曲、一個個小島 → 過擬合。γ 小 → 邊界平滑
epsilon（SVR）管子變寬 → 更多點不算誤差 → 模型更簡單
優點
  • 高維資料效果好（特徵數 > 樣本數也能用）
  • 只靠支援向量，泛化能力強
  • 用核函數處理非線性
缺點
  • 資料量大時訓練很慢（約 O(n²)～O(n³)）
  • 要調 C、γ，且要標準化
  • 沒有直接的機率輸出，也不好解釋

常考陷阱

  • C 和 γ 都是越大越容易過擬合。
  • SVM 的 C 是懲罰錯分的權重，跟邏輯迴歸的 C 一樣都是「越大正則化越弱」。
  • 要機率要設 probability=True，內部用 Platt scaling 另外估，會變慢。
from sklearn.svm import SVC
SVC(kernel='rbf', C=1.0, gamma='scale').fit(X_train_scaled, y_train)
08 · 機率

朴素貝氏 Naive Bayes

分類生成式模型訓練極快

用貝氏定理算「看到這些特徵時，屬於每一類的機率」，取最大的。「朴素」是指假設特徵之間在給定類別下互相獨立。

貝氏定理P(y | x) = P(x | y) · P(y)P(x)
獨立假設後ŷ = arg maxy P(y) · Πj P(xj | y)
  • P(y) 先驗機率（各類別的比例），P(xj|y) 概似（該類別下出現這個特徵值的機率），P(y|x) 後驗機率。
  • P(x) 對每一類都一樣，比大小時可以省略。
  • 實作上會取 log 把連乘變連加，避免數值太小。

三種變體

類別假設特徵是典型用途
GaussianNB連續值，各類別下呈常態分布一般數值資料（如鳶尾花）
MultinomialNB次數（字詞出現幾次）文字分類、垃圾郵件
BernoulliNB0／1（字詞有沒有出現）短文本、二元特徵

拉普拉斯平滑（Laplace Smoothing）

如果某個字在訓練資料的某類別裡從沒出現，P(xj|y) = 0，整串連乘就變 0。解法是每個計數都加 α（預設 α = 1）。sklearn 參數是 alpha。

優點
  • 訓練和預測都極快
  • 小資料、高維資料（文字）表現好
  • 可以逐批更新（partial_fit）
缺點
  • 獨立假設通常不成立
  • 輸出的機率值不準（太接近 0 或 1）
  • 特徵相關性強時效果下降

常考陷阱

  • 獨立假設雖然常不成立，但只要機率的大小順序對，分類結果還是準。
  • 零機率問題 → 拉普拉斯平滑。
  • 它是生成式模型：先學每一類「長什麼樣」P(x|y)，再反推 P(y|x)。
from sklearn.naive_bayes import MultinomialNB
MultinomialNB(alpha=1.0).fit(X_counts, y)   # X_counts 來自 CountVectorizer

分類／回歸可解釋不需要標準化

每一步挑一個特徵和切點，把資料分得「越純越好」，一路切下去形成樹狀的 if-else 規則。

  • 選讓不純度下降最多（資訊增益最大）的切法。sklearn 預設 Gini（criterion='gini'），用 CART 演算法，每次切成兩支。
  • 回歸樹：切分標準改成讓子節點的 MSE（變異）最小，葉節點預測值 = 該葉樣本的平均。

控制過擬合（剪枝）

超參數效果
max_depth最大深度。不設限會一直長到每片葉子都純 → 過擬合
min_samples_split節點至少有幾筆才能再切
min_samples_leaf每片葉子至少幾筆
ccp_alpha後剪枝（成本複雜度剪枝），越大剪越多

預剪枝：長樹時就限制（前三個）。後剪枝：先長完再剪掉沒幫助的分支（ccp_alpha）。

優點
  • 規則看得懂、可視覺化
  • 不需要標準化，數值、類別都能處理
  • 能抓非線性與特徵交互作用
缺點
  • 很容易過擬合
  • 不穩定：資料稍變，樹可能完全不同（高變異）
  • 邊界是階梯狀（只能垂直於軸切）

常考陷阱

  • 樹的高變異正是隨機森林要解決的問題。
  • Gini 和 Entropy 結果通常差不多；Gini 不用算 log，比較快。
  • 樹越深 → 偏差越低、變異越高。

10 · 集成

隨機森林 Random Forest

分類／回歸Bagging可平行

訓練很多棵「各自有點不一樣」的決策樹，分類投票、回歸取平均。很多棵高變異的樹平均起來，變異就降下來了。

兩種隨機

  1. 資料隨機（Bootstrap）：每棵樹從訓練集有放回地抽 n 筆。每次約有 63.2% 的不同樣本被抽到，剩下約 36.8% 沒被抽到，稱為 OOB（Out-of-Bag）樣本。
  2. 特徵隨機：每次切分只從隨機挑的一部分特徵裡找最佳切點（max_features，分類常用 √p）。這讓樹之間的相關性降低，平均起來效果更好。
訓練集→Bootstrap 抽 B 份→每份長一棵樹（切分時隨機選特徵）→投票／平均

Bagging = Bootstrap Aggregating。隨機森林 = Bagging + 特徵隨機。

重要超參數

n_estimators樹的數量。越多越穩定，通常不會因此過擬合，只是變慢
max_features每次切分考慮幾個特徵。越小 → 樹之間越不相關
max_depth 等同決策樹，限制單棵樹
oob_score=True用 OOB 樣本估泛化誤差，不必另切驗證集
優點
  • 準確度高、不太需要調參，實務常用
  • 比單棵樹抗過擬合
  • 提供特徵重要性；不需要標準化
  • 每棵樹獨立，可平行訓練
缺點
  • 模型大、預測比單棵樹慢
  • 失去單棵樹的可解釋性
  • 回歸時不能預測超出訓練範圍的值

常考陷阱

  • 隨機森林主要降低變異（Variance）；梯度提升主要降低偏差（Bias）。
  • Bootstrap 是有放回抽樣，同一筆資料可能被抽到好幾次。
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(n_estimators=300, oob_score=True, n_jobs=-1).fit(X_train, y_train)
rf.oob_score_, rf.feature_importances_
11 · 集成

梯度提升 Gradient Boosting（XGBoost／LightGBM）

分類／回歸Boosting循序訓練

一棵接一棵訓練淺樹，每棵新樹專門學「前面所有樹加起來還錯多少」（殘差），再用小步伐加進模型。

逐步相加Fm(x) = Fm−1(x) + η · hm(x)
  • hm 是第 m 棵樹，擬合損失函數的負梯度；用 MSE 時，負梯度剛好就是殘差 y − Fm−1(x)。
  • η 是學習率（learning rate），讓每棵樹只修正一點，避免一次修過頭。
  • 每棵樹通常很淺（深度 3～6），是「弱學習器」。

重要超參數

n_estimators樹的數量。太多會過擬合（和隨機森林不同），搭配 early stopping
learning_rateη。小學習率要配更多樹，通常泛化較好。兩者要一起調
max_depth單棵樹深度，通常小
subsample、colsample_bytree每棵樹抽部分樣本／特徵，增加隨機性、降過擬合
reg_alpha、reg_lambdaXGBoost 對葉節點權重的 L1／L2 正則化

XGBoost／LightGBM 改進了什麼

重點
XGBoost損失函數加入正則化項；用二階導數（梯度和 Hessian）找切點；內建處理缺值（學每個切點缺值該往哪邊走）；切點搜尋可平行化
LightGBM直方圖分箱加速；樹按葉生長（leaf-wise），每次挑誤差下降最多的葉子長，資料大時更快
優點
  • 結構化（表格）資料上常是準確度最高的
  • 支援正則化、缺值、自訂損失
  • 提供特徵重要性；不需要標準化
缺點
  • 超參數多、要仔細調
  • 樹要依序訓練，無法跨樹平行
  • 對雜訊和離群值較敏感，容易過擬合

常考陷阱

  • Boosting 是循序的，每棵樹依賴前一棵；Bagging 是平行的。
  • XGBoost 不在 scikit-learn 裡，要另外 pip install xgboost（sklearn 自己有 GradientBoostingClassifier、HistGradientBoostingClassifier）。
  • AdaBoost 也是 Boosting，但它是調整樣本權重（加重錯分的點）；梯度提升是擬合殘差／負梯度。
from xgboost import XGBClassifier
xgb = XGBClassifier(n_estimators=500, learning_rate=0.05, max_depth=4,
                    subsample=0.8, colsample_bytree=0.8, early_stopping_rounds=50)
xgb.fit(X_train, y_train, eval_set=[(X_val, y_val)])
