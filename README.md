## 筆記整理方式

1. **取得內容**：課程 Notion 頁面屬於老師的工作區，Notion 連接器讀不到，所以改用 Chrome（已登入的瀏覽器）開啟頁面讀取。
2. **讀完整頁面**：
   - 從總目錄頁抓出各講次連結，逐頁讀取文字。
   - 展開所有收合區塊（toggle），避免漏掉隱藏內容。
   - 一併讀取講次內的子頁面（例如 L01 的 Part 1–4、L03 的 Part 5 設計文件）。
3. **看圖片**：逐張截圖查看頁面上的圖片（架構圖、資訊圖表、截圖），把重點改寫成文字、表格或程式碼，補進對應的筆記。講師照片、書封這類沒有資訊的圖不收錄。
4. **寫成筆記**：每個講次一個 Markdown 檔，依「單元重點 → 課前準備 → 課程內容 → 作業／練習 → 附錄」整理；可以比較的內容做成表格，程式碼保留成程式碼區塊，prompt 保留原文方便直接複製。
5. **不收錄的內容**：
   - API key 等機密（例如頁面上的 CWA key）不抄進筆記。
   - 附件（ipynb、pdf、csv）只記檔名，不下載。
   - 看不清楚或被截斷的內容會註明，不自行猜測。
6. **命名規則**：檔名與資料夾一律用英文（`L05-linear-to-auto-regression.md`），內容用中文。
7. **網頁版**：把 L04-1 ～ L06 的筆記整理成一頁 HTML（左側講次導覽、表格、公式、可複製的 prompt，支援深色模式），發佈成 Claude artifact。
